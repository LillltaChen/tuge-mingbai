================================================================================
                              图个明白
                  右键图片，一键生成 AI 绘图提示词
================================================================================

【项目定位】
图个明白是一款 Chrome 浏览器扩展，基于多模态大模型（GPT-4o Vision）
的视觉理解能力，让用户在任意网页右键点击图片，即可生成中英双语、
带风格标签的 AI 绘图提示词。

核心口号：让每一张图片，都被读懂。


【核心功能】

1. 右键即用
   在任意网页右键点击图片，选择「✨ 图个明白：生成 AI 提示词」，
   3-8 秒内获得结构化提示词，无需离开当前页面。

2. 中英双语输出
   同时生成英文 Prompt 和中文提示词，支持实时编辑与自动互译同步。

3. 智能风格标签
   自动提取 4-6 个风格关键词（主题、风格、光线、色彩、情绪），
   支持单独复制。

4. 本地缓存加速
   最近 20 条分析结果本地存储（LRU 缓存），重复图片秒出结果。

5. 批量分析队列
   支持多张图片并行/串行分析，带进度面板和状态管理。

6. 精美浮窗面板
   毛玻璃效果、可拖拽缩放、明暗主题切换、AI 扫描动画。


【技术栈】

- Chrome Extension Manifest V3
- Vanilla JavaScript（零框架依赖）
- OpenAI Chat Completions API（Vision 模式）
- chrome.storage.local（本地持久化）

【安装方法】

1. 下载或克隆本仓库
2. 打开 Chrome，进入 chrome://extensions/
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目文件夹
5. 点击扩展图标，配置 API Key 即可使用

【配置说明】

| 配置项  | 说明                          | 默认值                   |
|---------|-------------------------------|--------------------------|
| API Key | OpenAI / Gemini / Claude 密钥 | —                        |
| Base URL| API 服务地址                  | https://api.openai.com   |
| 模型    | 需支持 Vision 能力            | gpt-4o                   |

所有配置仅存储在本地浏览器，不会上传至任何服务器。


【设计哲学】

- 隐形的工具：没有常驻 UI，只在右键菜单中静静等待
- 愉悦的细节：扫描动画、复制涟漪、拖拽弹性、主题切换
- 尊重隐私：API Key 和历史记录只存本地
