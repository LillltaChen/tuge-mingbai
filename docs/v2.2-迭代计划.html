核心功能

🖱️

右键识别

在任意网页图片上右键，选择「图个明白」即可启动 AI 分析

🌐

三语切换

EN / 中 / JSON 三种模式一键切换，单卡片显示 + 底部标签切换

🏷️

智能标签

自动提取 4-6 个关键词标签，覆盖主体、风格、光影、色彩、氛围

🔄

实时同步

编辑一种语言时，后台自动翻译并同步到另一种语言

📜

历史记录

右侧边栏展示最近分析记录，显示"共识别 X 张"，支持快速回看

⚡

智能缓存

已分析图片自动缓存，二次打开秒级响应，无需重复调用 API

🌙

主题切换

Light / Dark 双模式，默认 Dark，右上角太阳/月亮图标一键切换

📐

位置记忆

拖拽调整的位置和大小自动保存到 chrome.storage.local，刷新页面保持原样

🔬

科技感动画

图片呼吸 + 扫描线 + 光点脉冲 + 打字机文字，四重动画层层递进

🍎

极简窗口

仿 macOS 窗口样式，仅保留关闭和最小化按钮，简洁高效

文件结构

文件 职责
manifest.json 插件配置、权限声明、入口定义
content.js 页面注入、面板 UI、拖拽缩放、主题切换、语言模式、扫描动画、交互逻辑
background.js Service Worker、右键菜单、API 调用、缓存管理、队列处理
options.html 设置页面：API Key、Base URL、Model 配置
popup.html 浏览器图标点击弹窗

迭代建议

1

分析历史持久化 高优先级

目前 history 数组在页面刷新后丢失。建议存入 chrome.storage.local，支持历史记录查询和导出功能

2

批量管理历史 中优先级

随着识别数量增加，需要支持批量清空历史记录，以及单条删除能力

3

快捷键支持 中优先级

支持 Ctrl+Shift+P 快捷键快速唤起面板，Escape 关闭面板，提升使用效率

4

分析结果导出 低优先级

支持将识别结果导出为 Markdown / JSON / 图片注释格式，方便在文档中复用

5

提示词模板库 低优先级

保存常用提示词片段，支持快速插入和复用，方便高频场景

6

多语言提示词优化 低优先级

目前 EN 模式是直译，部分表述可以更符合英语母语习惯。JSON Schema 格式也可进一步优化

7

面板最小化状态记忆 低优先级

记录面板是否处于最小化状态，刷新后保持最小化而非默认展开

8

多模型支持 低优先级

接入 Claude Vision、Gemini 等更多 AI 服务，供用户选择
