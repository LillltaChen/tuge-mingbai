功能特性

为 AI 绘图工作流设计的全能图片分析工具

🖱️

右键即用

在任意网页右键点击图片即可触发分析，无需切换页面或上传文件，体验无缝衔接。

🌐

中英双语输出

同时生成英文 Prompt 和中文提示词，支持实时编辑与自动互译同步，满足不同平台需求。

🏷️

智能标签提取

自动识别图片的主题、风格、光线、色彩、情绪等维度，提取 4-6 个可单独复制的关键词。

⚡

本地缓存加速

最近 20 条分析结果本地缓存，重复图片秒出结果，历史记录以缩略图形式在侧边栏展示。

📦

批量分析队列

支持同时分析多张图片，实时显示进度条和队列状态，完成后自动汇总结果。

🎨

精美浮窗面板

毛玻璃效果浮窗，支持拖拽移动、自由缩放、明暗主题切换，面板状态自动持久化。

从想法到产品

这个项目是如何从 0 到 1 做出来的

💡

发现痛点

经常在网上看到惊艳的 AI 绘图作品，却不知道怎么写出类似的提示词。截图 → 打开 ChatGPT → 上传 → 打字描述需求 → 复制结果，这个流程太繁琐了。为什么不能右键图片直接出提示词？

🔬

验证可行性

先做一个 30 行的油猴脚本测试核心链路：右键获取图片 URL → 用 fetch 调用 GPT-4o Vision API → console.log 返回结果。验证通过：浏览器扩展是最自然的入口，用户无需离开当前页面。

🛠️

MVP 版本

用 Manifest V3 搭起骨架：background.js 注册右键菜单，content.js 注入一个简单的 div 显示结果。第一版只有「右键 → 分析 → 显示英文提示词」三个动作，但核心体验已经跑通了。

🌍

双语与结构化

发现用户群体中英文都有需求，且需要「风格标签」来快速理解画面。让 AI 返回 JSON 格式 {english, chinese, style, tags}，前端解析后分区域展示，支持点击标签单独复制。

⚡

缓存加速

同一个图片反复分析太浪费 Token。引入 LRU 缓存机制（chrome.storage.local 存 20 条），二次访问秒出结果。同时加入历史侧边栏，已分析过的图片以缩略图形式快速回顾。

📦

批量队列

用户反馈：「能不能一次分析多张图？」于是加入批量队列系统，带进度面板和状态管理（等待中/分析中/已完成/失败），支持取消和重试，满足素材整理场景。

✨

UI 打磨与细节

花大量时间打磨交互体验：毛玻璃浮窗可拖拽缩放、AI 扫描动画、打字机效果、明暗主题切换、复制涟漪反馈、响应式字体适配……好的工具，用起来应该是愉悦的。

使用方法

三步开启 AI 提示词生成之旅

1

配置 API

点击扩展图标进入设置页，填入你的 OpenAI / Gemini / Claude API Key，选择支持 Vision 的模型（推荐 gpt-4o）。

→
2

右键分析

在任意网页上右键点击图片，选择「✨ 图个明白：生成 AI 提示词」，AI 将自动识别图片内容。

→
3

复制使用

浮窗展示生成的提示词和风格标签，点击「复制」即可粘贴到 Midjourney、Stable Diffusion 等工具中使用。

AI 分析流程

从图片到提示词的技术链路

// 1. 获取网页图片
右键点击图片 → 提取 src / currentSrc → base64 编码

// 2. 调用 Vision API
POST /v1/chat/completions
model: "gpt-4o"
messages: [
  { role: "system", content: "分析图片生成 JSON 提示词..." },
  { role: "user", content: [
    { type: "image_url", image_url: { url: "data:image/jpeg;base64,..." } }
  ]}
]

// 3. 解析返回结果
{ english: "...", chinese: "...", style: "...", tags: [...] }
